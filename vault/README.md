# Project Vault Evidence

This folder stores evidence and history. It is not the active docs system.

| Folder | Purpose |
| --- | --- |
| `sessions/` | Operational session notes and handoff evidence. |
| `research/` | Source-backed research and verification records. |
| `notes/` | Durable insights that are not yet decisions. |
| `snapshots/` | Backups of source-of-truth docs such as `VAULT.md`. |
| `archive/` | Vault-local historical material; review against any top-level `archived/` folder. |

Keep polished, user-facing, or subsystem-specific docs in the project docs,
strategy, operations, or subsystem folders. Use `vault/` for proof.
